# 02 Counter — React + TypeScript + Vite

## Результат

Приложение постоянно показывает текущее значение счётчика. Increase прибавляет один, Decrease вычитает один, Reset возвращает ноль. Выполнен Bonus: значение не опускается ниже нуля.

React-компонент хранит число в `useState<number>`, а чистая функция `nextCounterValue` вычисляет переход для одного из трёх действий типа `CounterAction`.

## Требования к окружению

- Node.js `^20.19.4 || >=22.12.0`: подходит Node 20 начиная с 20.19.4 либо Node 22 начиная с 22.12.0 и более новые версии; Node 21 и Node 22.0–22.11 не подходят Vite 7.
- npm, установленный вместе с Node.js.

```bash
node --version
npm --version
```

## `npm install` и `npm ci`

- `npm ci` устанавливает точные версии из существующего `package-lock.json` и пересоздаёт `node_modules`; используйте после клонирования и перед сдачей.
- `npm install` разрешает диапазоны из `package.json` и может обновить lock-файл; используйте при первом создании проекта или намеренном добавлении зависимости.

Не удаляйте `package-lock.json` и не заменяйте `npm ci` на `npm install`, чтобы скрыть ошибку окружения.

## Ручная проверка

1. После загрузки видно `Current value: 0`.
2. Два нажатия Increase дают 2.
3. Одно нажатие Decrease даёт 1.
4. Reset возвращает 0.
5. Повторные нажатия Decrease на нуле оставляют 0.

## Частые ошибки

- Обычная переменная `let value = 0` не является React state и не вызывает перерисовку.
- `setValue(value + 1)` использует значение из текущего рендера; функциональная форма получает актуальное состояние.
- `value - 1` нарушает Bonus; нижняя граница задаётся `Math.max(0, value - 1)`.
- Корневой `App.tsx`, Expo, `react-native` и `StyleSheet` относятся к другому типу проекта.
