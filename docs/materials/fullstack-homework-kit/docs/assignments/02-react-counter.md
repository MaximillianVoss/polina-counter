# Исходное задание — React: Counter

## Статус

Основное задание, оцениваемое в 3 балла. Отдельно указан необязательный Bonus: не позволять значению счётчика опускаться ниже нуля.

## Что требуется

- Создать новое React-приложение со счётчиком.
- Добавить три кнопки:
  - `Increase` — увеличивает значение счётчика на 1;
  - `Decrease` — уменьшает значение счётчика на 1;
  - `Reset` — возвращает значение счётчика к 0.
- Текущее значение счётчика должно быть хорошо видно.
- Значение должно обновляться сразу после нажатия кнопки.
- Bonus: не допускать уменьшения счётчика ниже 0.

## Ожидаемый результат

Пользователь видит текущее значение и управляет им тремя кнопками: увеличивает на единицу, уменьшает на единицу или сбрасывает до нуля. При выполнении Bonus повторное уменьшение на нуле оставляет значение равным нулю.

## Что сдавать

Формат сдачи в исходном задании не указан.

## Примечания к трактовке

- `useState` перечислен в источнике в разделе «Что уже известно», а не как отдельный пункт требований к сдаче.
- Начальное значение счётчика отдельно не задано; ноль прямо указан только как результат действия `Reset` и нижняя граница Bonus.
- Требования к стилям, тестам, сборке и сохранению значения после перезагрузки в источнике не указаны.
